## 🌟 Features

- 🔒 **Secure Admin Setup**: Initial password protection requiring immediate change upon first login.
- ⚙️ **Dynamic Environment Management**: Configure JWT, ports, passwords, API servers, and keys via an intuitive web interface.
- 🐳 **Containerized & Ready**: Fully automated CI/CD pipelines for GHCR Docker image builds.
- 🛡️ **Security First**: Integrated TruffleHog secret scanning and robust authentication boundaries.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/jbkunama1/tRive.git
cd tRive

# Run with Docker
docker compose up -d
```
