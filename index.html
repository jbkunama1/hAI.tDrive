🚀 tRive

Dein farbenfrohes, modernes Cloud-Drive-Frontend fuer tDrive (Telegram-Drive) 🎨 — mit Passwort-Login 🔐, Datei-Management 📁 und Android-App-Wrapper 📱.

🐳 Docker + GHCR ⚙️ GitHub Actions CI/CD 🔐 JWT + bcryptjs Auth 📡 tDrive REST API 🌈 Modern & Animiert
⭐ Repo auf GitHub 🌐 Live-App oeffnen

✨ Features

🔐

Passwort-Login

Sicherer Zugriff via bcryptjs-Hash und JWT-Session-Tokens.

📁

Dateiverwaltung

Listen, hochladen, herunterladen, umbenennen, verschieben, loeschen.

🔍

Suche & Sortierung

Schnelle Volltextsuche und flexible Sortieroptionen.

🔗

Share-Links

Dateien mit optionalem Passwortschutz teilen.

📊

Speicher-Statistik

Uebersicht ueber Speichernutzung und Dateianzahl.

📱

Mobile-First

Optimiert fuer Android-WebView-Wrapper und Touch-Bedienung.
